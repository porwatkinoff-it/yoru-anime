# Yoru Anime

Клиент [Anime 365](https://smotret-anime.app) для iPhone/iPad, Android-телефонов и Android TV (SberBox).
Без браузерной оболочки, рекламы, аналитики и собственных серверов — только официальный API Anime 365
и ваш аккаунт.

## Скачать

Последняя версия — на странице [Releases](../../releases/latest):

- **Android и Android TV** — `YoruAnime-<версия>-Android.apk`, Android 9+, ARMv7/ARM64.
- **iPhone и iPad** — `YoruAnime-<версия>-iOS.ipa`, iOS 17+. Файл без подписи: подпишите его своим способом
  (например, GBox или своим сертификатом). Имя файла меняется с каждой версией, чтобы установщики не брали старую копию.

## Обновления

- **Android/TV**: приложение само раз в несколько часов проверяет новый релиз на GitHub, показывает, что нового,
  скачивает APK и открывает системное окно «Обновить приложение?». Первый раз Android попросит разрешить
  Yoru Anime устанавливать приложения. Вручную: Аккаунт → «Проверить обновления».
- **iPhone/iPad**: iOS не даёт приложению поставить IPA само, поэтому Yoru Anime сообщает о новой версии и
  открывает страницу релиза, откуда её можно скачать и подписать.

## Возможности

- Главная в духе стриминговых сервисов: баннер, «Продолжить просмотр» с прогрессом, новые серии в избранном,
  онгоинги, лучшее года, фильмы, подборки по жанрам.
- Страница аниме: оценка, жанры, описание, серии с прогрессом, «Похожие».
- Поиск с жанрами, расписание выхода серий по дням недели, «Моё» (список и история).
- Выбор перевода без мусора: русские субтитры и озвучка, отметки BD (Blu-ray) и 4K, другие языки — отдельно.
- Плеер VLC: ASS-субтитры, качество до 4K, «Пропустить опенинг» (88 с), скорость, «Следующая серия».
- Загрузки на телефоне: серия или весь сезон, в фоне, качество вплоть до «Наилучшее», только по Wi‑Fi,
  удаление просмотренных, просмотр без интернета.
- Аккаунт: статус подписки Anime 365 и проверка скорости видеосерверов с выбором самого быстрого.
- Синхронизация истории с телевизором в домашней сети (через Yoru Air на приставке).

## Вход и данные

Почта и пароль вводятся в приложении и отправляются только на HTTPS API Anime 365. Пароль не сохраняется,
токен лежит в Связке ключей iOS или зашифрован ключом Android Keystore. Для видео нужна подписка Anime 365.
Постеры, описания, видео и переводы принадлежат правообладателям и загружаются из Anime 365 — в репозитории их нет.

## Сборка Android

JDK 21, Gradle 8.7, Android SDK 35. В `android/local.properties` укажите `sdk.dir=...`.
Подпись берётся из переменных окружения: `KEYSTORE_PATH`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
(ключ в репозиторий не входит; обновления ставятся поверх только при той же подписи).

```bash
gradle -p android assembleRelease
```

## Сборка iOS

Xcode с iPhoneOS SDK и Python 3.

1. Скачайте `VLCKit-all.xcframework.zip` 3.6.0:
   https://github.com/tylerjonesio/vlckit-spm/releases/download/3.6.0/VLCKit-all.xcframework.zip
   (SHA-256 `5da4747e001900bbb4153f58db2be4695096c9c2350aea00376ad67b39c053f6`)
   и распакуйте `VLCKit-all.xcframework` в `reference/`.
2. `python3 ios/generate-project.py`
3. `xcodebuild -project ios/NightAnime.xcodeproj -scheme NightAnime -configuration Release -sdk iphoneos CODE_SIGNING_ALLOWED=NO build`
4. `python3 package.py` соберёт неподписанный IPA.

Внутренние идентификаторы (`com.resvvt.nightanime…`, папки `NightAnime`) остались от прежнего названия:
так новые версии ставятся поверх старых и сохраняют историю и вход.
